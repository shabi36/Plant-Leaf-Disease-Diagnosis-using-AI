🌿🔬 Plant Leaf Disease Diagnosis using AI

🚀 Project Overview

This project is an AI-powered plant disease diagnosis system where users can upload a picture of a plant leaf, and the Google Gemini Pro Vision model analyzes it to detect diseases. 🌱🤖 This can help farmers, gardeners, and researchers quickly identify plant diseases and take necessary actions to prevent crop damage. 🌾🍃

🎯 Objective

✅ Build an AI-driven web app for plant disease detection.
✅ Utilize Google Gemini Pro Vision to classify diseases from leaf images.
✅ Provide accurate and fast results to help users diagnose plant health issues.

📸 How It Works?

1️⃣ User uploads an image of a plant leaf 🌿📷.
2️⃣ The image is processed and sent to Google Gemini Pro Vision. 🖼️🧠
3️⃣ The AI model analyzes the image and predicts the disease type. 🦠🔍
4️⃣ The user receives a detailed diagnosis with possible treatment suggestions. 🏥🌾

🏗 Tech Stack

🖥️ Frontend: HTML, CSS, JavaScript (for UI/UX).
🚀 Backend: Python (Flask/Django for API).
🧠 AI Model: Google Gemini Pro Vision.
☁️ Cloud Services: Google Cloud for model integration.

🌱 Features

🌿 Image-Based Diagnosis – Upload a plant leaf image for instant analysis.
🤖 AI-Powered Detection – Uses Google Gemini Pro Vision for disease identification.
📊 User-Friendly Dashboard – Simple interface for non-tech users.
🛠 Preventive Measures – Suggests remedies and treatments.
📡 Cloud-Based – Accessible from anywhere via the web.

📋 Supported Diseases (Example)

🌾 Powdery Mildew – White powdery patches on leaves.
🍃 Leaf Rust – Reddish-brown spots on the leaf surface.
🌻 Bacterial Blight – Water-soaked lesions that turn brown.
🌿 Healthy Leaf Detection – Identifies if the plant is disease-free.
